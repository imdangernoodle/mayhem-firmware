Design Intent

This pass keeps Mayhem's compact grid but makes the hierarchy more legible: action first, app name second, with Echidna visible in quiet spaces instead of fighting selected text.

Hardware Rules

  • No large art baked into flash.
  • Selected tiles stay solid for readability.
  • Character sprites appear only when large enough to read.

Next Firmware Targets

  • Softer selected tile border and fill.
  • Consistent category title bar treatment.
  • Bitty as receive/transmit activity state, not tiny decoration.
Splash/source mood: high contrast, old-library warmth, witch imagery without sacrificing the small-screen text surface.
